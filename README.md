# PDF Editor Kit for Windows: downloads

Free PDF editor for Windows 10 and 11. No ads, no sign-up, your files never leave your PC.

**Download:** see the latest release on the right, or go to https://pdfeditorkit.app/download

This repository only holds the download files. The website is https://pdfeditorkit.app and the contact is support@pdfeditorkit.app.

The installer is not signed with a paid certificate, so Windows may show "Windows protected your PC" the first time: click **More info**, then **Run anyway**.
